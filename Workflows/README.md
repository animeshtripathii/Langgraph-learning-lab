# Workflows

This folder contains workflow implementations from my LangGraph and Agentic AI learning practice.

## Available Files

| File | Purpose | Level |
|---|---|---|
| `LLM_Squential_workflow.js` | Sequential flow driven by LLM reasoning steps | Intermediate |


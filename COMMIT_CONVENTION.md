# Commit Message Convention

Use this format for clean and searchable history:

```text
<type>: <short summary>
```

## Types

- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation only
- `refactor`: Code changes without behavior change
- `test`: Add or update tests
- `chore`: Maintenance tasks (deps, config, tooling)

## Rules

- Keep summary short (ideally under 72 characters)
- Use present tense ("add", "fix", "update")
- Use lowercase type
- One commit should focus on one logical change

## Examples

```text
feat: add sequential workflow runner
fix: handle missing API key in workflow setup
docs: update learning roadmap in README
chore: add github actions ci workflow
```
